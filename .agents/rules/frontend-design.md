# Frontend & UI/UX Design Rule

Core principle: Create distinctive, intentional, and master-crafted visual interfaces grounded in the POS & Angkringan domain. Never settle for generic AI template defaults.

## 1. Intentional Visual Identity & Restraint
- **Domain-Grounded Aesthetics**: Angkringan Jogja identity combines warm, grounded hospitality with sleek modern digital efficiency.
- **Spend Boldness in One Place**: Let one key element be memorable per screen (e.g., prominent total bill badge, crisp receipt preview, or cashier action bar), and keep supporting chrome quiet and disciplined.
- **Avoid Generic SaaS-Card Kits**: Do not chop every screen into monotonous identical cards with uniform grey shadows and decorative gradient washes.
- **Structural Devices as Information**: Borders, dividers, subtle backgrounds, and badges must encode operational state (e.g., Lunas vs Belum Lunas, Hadir vs Terlambat), never decorative clutter.

## 2. Touch-Screen POS Ergonomics (Tablet First)
- **Generous Touch Targets**: All interactive elements (buttons, keypad keys, table pills, quantity steppers) must have a minimum touch target of 44x44px.
- **High-Contrast Legibility**: Cashier screens must remain effortlessly readable under all lighting conditions (bright daylight or dim evening angkringan lighting).
- **Proportional Spacing**: Every card, modal, and sheet must have balanced padding (16-20px) and rounded corners (10-14px) without content bleeding into borders.

## 3. UX Copywriting & State Communication
- **Active & Direct Verbs**: Buttons describe the exact outcome ("Simpan Transaksi", "Cetak Nota", "Buka Sesi").
- **Clear Empty States**: Empty states must explain what is missing and provide an immediate call-to-action button (e.g., "+ Tambah Menu Pertama").
- **Actionable Error States**: Error alerts state clearly what happened and how to fix it, avoiding technical stack traces in end-user dialogs.
